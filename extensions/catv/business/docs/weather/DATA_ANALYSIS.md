### 2. 코드 사용법 (Python)

```python
# EUC-KR 파일 읽기
with open('3hour.dat', 'r', encoding='euc-kr') as f:
    lines = f.readlines()
    header = lines[0].strip().split('#')
    for line in lines[1:]:
        fields = line.strip().split('#')
        region, time, icon, weather, temp, rain_prob = fields[:6]
        print(f"{region} {time}시: {temp}°C, {weather} ({rain_prob}%)")

# 지역 코드 조회
def get_region_code(region_name):
    with open('match_code.txt', 'r', encoding='euc-kr') as f:
        for line in f:
            code, location = line.strip().split('=')
            if region_name in location:
                return code
    return None

code = get_region_code("서울특별시 강남구")  # → 135
```

## 주의사항

1. **인코딩 변환 필수**: 모든 파일이 EUC-KR이므로 UTF-8 시스템에서는 변환 필요
   ```bash
   iconv -f EUC-KR -t UTF-8 3hour.dat > 3hour_utf8.dat
   ```

2. **빈 값 처리**: "-" 문자는 데이터 없음을 의미

3. **중복 코드**: match_code.txt에서 동일 코드가 여러 지역에 매핑됨

4. **실시간성**: 특보(ktko.dat)는 수시 갱신, 나머지는 1일 1~3회 갱신

## 분석 도구

```bash
# 전체 파일 UTF-8 변환
for f in *.dat *.txt; do 
  iconv -f EUC-KR -t UTF-8 "$f" > "${f%.dat}_utf8.dat"
done

# 특정 지역 데이터만 추출
grep "서울" 3hour.dat

# 날씨 아이콘 분포 확인
cut -d'#' -f3 3hour.dat | sort | uniq -c

# 지역별 레코드 수
cut -d'#' -f1 land.dat | sort | uniq -c | sort -rn
```
