STB 제어 및 모니터링
사용자 매뉴얼

CATV 셋톱박스(STB)에 제어 명령을 예약·실행하고 결과를 조회하는 기능입니다.

1화면 구성 개요

STB 제어 및 모니터링 기능은 스케줄 설정에 의한 즉시 제어, 예약 제어, 반복 제어 실행을 지원합니다. 각 실행 타입은 스케줄 등록 버튼을 누른 후 다이얼로그에서 선택할 수 있습니다 (스케줄 등록의 그림 3-1 참고).

STB 제어 및 모니터링 페이지는 다음 탭 구조로 구성됩니다.

탭설명
스케줄 목록등록된 제어 스케줄 전체 목록, 등록·수정·삭제 가능
스케줄 결과스케줄 실행 결과 목록 (결과 행 클릭 시 상세 탭 추가)
결과 상세 탭스케줄 결과 행 클릭 시 동적으로 추가되는 개별 탭
💡 결과 상세 탭은 여러 개를 동시에 열 수 있으며, 탭 제목 우측의 × 버튼으로 닫을 수 있습니다.

스케줄 목록 탭에서는 등록된 모든 제어 스케줄을 확인할 수 있습니다.

  • 행을 클릭하면 스케줄 상세 시트가 열립니다.

3스케줄 등록

스케줄 목록 우측 상단의 [스케줄 등록] 버튼을 클릭하면 스케줄 등록 탭이 추가됩니다. 탭 제목 우측의 ×를 클릭하거나 [취소] 버튼으로 탭을 닫을 수 있습니다.

🔒 권한 필요: extension:catv:create 권한이 있어야 버튼이 표시됩니다.

예시설명

대상 선택

계층 구조(SO → L3 → Cell)를 선택합니다.

항목필수설명
SO✅서비스 지역(SO) 선택
L3—미선택 시 전체 L3 대상 (기본: 전체 선택)
Cell—미선택 시 전체 Cell 대상 (기본: 전체 선택)

제어 대상 결정 우선순위

  1. Cell 일부 선택 → Cell 단위 제어
  2. L3 일부 선택 (Cell 전체) → L3 단위 제어
  3. L3 전체 + Cell 전체 → SO 단위 제어
⚠️ 수정 모드에서 이미 삭제된 L3 또는 Cell 항목은 (삭제됨) 표시와 함께 경고 메시지가 나타납니다. 해당 항목을 제거한 후 저장하는 것을 권장합니다.

제어 명령

제어 명령설명
stb_request_infoSTB 정보 수집 요청
smartRebootSTB 스마트 리부팅

설정 내용은 폼 하단의 설정 요약에서 실시간으로 확인할 수 있습니다. [스케줄 등록] 버튼 클릭 시 저장되며, 성공·실패 토스트 메시지가 표시됩니다.

4스케줄 수정

스케줄 목록의 [수정] 버튼을 클릭하면 스케줄 수정 탭이 추가됩니다. 화면 구성은 스케줄 등록과 동일하며, 탭 닫기(×) 또는 [취소] 버튼으로 에디터를 닫을 수 있습니다.

  • 즉시 실행 타입의 스케줄은 수정 버튼이 표시되지 않습니다.
  • 한번 실행 타입이고 실행 시간이 현재 이전인 경우 수정 버튼이 표시되지 않습니다.
  • 스케줄 이름은 수정할 수 없습니다 (읽기 전용).
  • 나머지 항목을 수정한 후 [스케줄 수정] 버튼으로 저장합니다.
  • 수정 모드에서는 삭제된 L3·Cell 항목이 (삭제됨)으로 표시됩니다.
🔒 권한 필요: extension:catv:update 권한이 있어야 수정 버튼이 출력됩니다.

5스케줄 삭제

스케줄 목록의 [삭제] 버튼을 클릭하면 확인 팝업이 표시됩니다.

  • 팝업에서 확인을 선택하면 스케줄이 영구 삭제됩니다.
  • 삭제 후 목록이 자동으로 갱신됩니다.
⚠️ 주의: 삭제된 스케줄은 복구할 수 없습니다.

8스케줄 결과 상세

스케줄 결과 목록에서 행을 클릭하면 탭이 추가되어 개별 STB 레코드를 조회할 수 있습니다.

탭 이름은 스케줄이름 · 월/일 시:분 형식으로 표시됩니다.

검색

우측 상단 검색창에서 다음 값으로 필터링할 수 있습니다.

입력 예시동작
대기 / 진행 중 / 성공 / 실패한글 상태명으로 필터링
pending / running / succeeded / failed영문 상태값으로 필터링
MAC 주소, K8s Job 이름, 결과 값텍스트 검색

컬럼 표시 설정

우측 상단 [컬럼] 버튼으로 표시할 컬럼을 선택·해제할 수 있습니다.

  • 기본 컬럼: 시작 시간, 모델명, CM MAC, STB MAC, 진행 상태, 종료 시간, 경과 시간, 결과 코드, 결과 메시지, 스케줄 이름, 스케줄 타입, K8s Job (12개 — 모두 토글 가능)
  • work_type별로 초기 숨김 항목이 다릅니다. 일반 명령은 시간·결과 코드가 기본 표시되고, stb_request_info는 결과 코드·메시지·스케줄 정보가 기본 숨김입니다.

stb_request_info 전용 보기

제어 명령이 stb_request_info인 경우, 결과 메시지(JSON)를 파싱하여 STB 정보 키별 동적 컬럼으로 표시합니다.

  • 기본 표시 컬럼: 시작 시간, 모델명, CM MAC, STB MAC, 진행 상태
  • 기본 숨김 컬럼: 종료 시간, 경과 시간, 결과 코드, 결과 메시지, 스케줄 이름, 스케줄 타입, K8s Job
  • 동적 컬럼: JSON 키 목록 (예: sw_version, hw_version 등)

10상태 및 진행 현황 안내

작업 상태

상태배지 예시설명
대기 대기 아직 처리되지 않은 상태
진행 중 진행 중 현재 STB에 명령 전송 중
성공 성공 정상적으로 완료됨
실패 실패 처리 중 오류 발생

진행 현황 배지

  • 완료 N   성공한 STB 수
  • 실패 N   실패한 STB 수 (1건 이상일 때만 표시)
  • 전체 N   총 대상 STB 수
ℹ️ 성공과 실패가 함께 존재하는 경우 결과 상태는 완료로 표시됩니다. 실패 건수는 진행 현황 배지에서 확인하세요.

실시간 갱신

진행 중(running) 또는 대기 중(pending) 상태의 작업이 있을 경우:

  • 스케줄 결과 목록: 5초마다 자동 갱신
  • 결과 상세 탭: 5초마다 자동 갱신 (녹색 점 애니메이션 표시)

모든 작업이 완료되면 자동 갱신이 중단됩니다.
