## SQLite DB 사용 시 주의사항

### 시간 포맷
1. 현재 사용중인 "modernc.org/sqlite" 드라이버 패키지에서 별도의 설정이 없는 경우 time.Time 타입을 SQLite에 저장할 때 t.String() 함수를 사용하여 `s := t.Format("2006-01-02 15:04:05.999999999 -0700 MST")` 형식의 문자열로 변환하여 저장합니다.
   * `2006-01-02 15:04:05.999999999 -0700 MST` -> `2025-09-26 02:27:54.3122031 +0000 UTC`
   * 아래 `strftime('%Y-%m-%d %H:%M:%f', 'now')` 함수와 일치 시키기 위해 밀리초 단위까지만 사용하려면 `t.Format("2006-01-02 15:04:05.999")` 형식으로 변환하여 저장해야 합니다.
2. SQLite CURRENT_TIMESTAMP 함수는 "YYYY-MM-DD HH:MM:SS" 형식의 문자열을 반환합니다.
3. SQLite julianday 함수를 사용하면 약 0.1µs 해상도로 시각을 표현 가능하지만 실제 OS 시계의 해상도의 영향을 받습니다.
4. SQLite 에서 밀리초 정밀도로 시간을 저장: strftime('%Y-%m-%d %H:%M:%f', 'now')
   * `2025-09-26 02:27:54.312`
